## Unreleased

- **Claude Code's questions.** When Claude Code asks through its AskUserQuestion tool, the tool card shows the questions with their header, options and descriptions (one choice, or several where the question allows), an **Other…** answer and **Answer** / **Skip**; the answers go back to Claude Code, in every approval mode, and stay under the card. The AI button counts a waiting question.
- **Readable tool cards.** A card's arguments and result are pretty-printed JSON with coloured keys, strings, numbers and literals (a light and a dark palette), in boxes at most 200 px tall that scroll; other text stays plain.
- **Selection as context.** A chip above the message box shows the editor selection (level actors, Content Browser assets), live (level changes at once, the rest polled every second while the panel is open). It goes with the next message as context; ✕ drops it for that message, and Project Settings ▸ AI Assistant ▸ "Attach the editor selection to messages" turns it off.
- **@ mentions.** `@` opens a list of the project's assets (type icons), folders and the level's actors, filtered as you type, with ↑/↓, Enter/Tab and Esc. Mentions reach the model as project-relative paths and actor ids. For every provider the selection and mentions go in a compact `<editor_context>` block before the text; the chat shows a one-line "Context: …" under the message. It works next to Claude Code's `/` list.
- **Plan mode awareness.** The model is told its approval mode every turn; in Plan mode it proposes a plan with the (hidden) tools it would use instead of saying it cannot find them. A Plan turn that needed changes shows **Switch to Ask to let MiniAI make these changes** with a one-click switch. Claude Code gets the mode in an `<editor_context>` block with each message, and its Plan refusals show the same chip.
- **Multilingual tool selection.** The toolset keywords cover Turkish (stems such as sahne, ekle, oluştur, yerleştir, oyna, çalıştır, test et, with Turkish case folding), Spanish, German and French; a request that matches no group gets the level, asset and view tools instead of level alone.
- **Thinking row.** A model's reasoning shows as one collapsed row above its answer: "Thinking…" with animated dots while it thinks, "Thought for N s" after; a click shows the reasoning as it streams, in a 100 px box that follows the text unless you scroll up. Reasoning is read from `reasoning_content`, `reasoning`, inline `<think>` tags (no longer leaking into the answer) and Claude Code's thinking blocks. The duration is saved with the chat.
- **Screenshots reach the model.** Images in tool results (`viewport_screenshot`, `pie_advance`, `pie_play_for`, `asset_editor_screenshot`) no longer become `[image]`: a model with vision gets the newest two as images, a text-only model a note with the image's type, size and dimensions. **Model accepts images** in Model provider… (automatic from the model name, editable) decides which. Tool cards show the images as thumbnails that open full size, for every provider, Claude Code included. A chat keeps the pixels of its newest 12 images.
- **Claude Code** is a model provider: MiniAI runs your installed, logged-in `claude` CLI headless in the project folder, one process per chat (resumed with `--resume` after a restart), with no key of its own. Its editor tool calls come through the editor's MCP server as tool cards, its permission requests follow the chat's approval mode (approval cards in Ask), and Undo this turn covers its level and file changes. `/` lists the CLI's commands with their descriptions. Model provider… shows the detected `claude`, its version and login state; the panel shows the model, the session and its cost.

- **↶ Undo this turn** under each assistant turn takes back its level step (only while it is the newest in Edit ▸ Undo) and restores every file its `fs_*` calls changed; the undone state is kept with the chat. Each turn's tool calls now carry their own caller id `miniai:<chat>:<n>`.
- **Project Settings ▸ AI Assistant** adds a preferred model provider (for the session, the user's own choice is kept), tool groups the assistant never gets, a cap on tool rounds per turn and project notes for its instructions. **Plugins ▸ MiniAI ▸ API Keys…** lists each provider's key source and the stored keys, masked, with Remove; `credentials.json` is mode 0600 on Linux and macOS.
- **Plugins ▸ MiniAI ▸ Connect External Agents…** registers the editor's MCP server with Antigravity (`~/.gemini/config/mcp_config.json`) and Claude Code (the project's `.mcp.json`) through the stdio bridge: no token in the file, other servers kept, the old file backed up, an unreadable file never overwritten.
- **Project Settings ▸ Plugins ▸ AI Assistant**: the project's default mode for new chats, saved in the `.lmproject`.
- Chats are kept with the project (`.lumina/plugins/lumina_plugin_miniai/`) and come back when it reopens. **+ New** starts a chat, the title edits in place, and **History** lists the project's chats (pinned first, then the latest) with search over titles and content, rename, pin and a confirmed delete.
- `dart run tool/pack_plugin.dart` packs the plugin for the Lumina Marketplace: `build/pack/lumina_plugin_miniai-<version>.zip` without build outputs, IDE folders, logs and secrets, checked against the marketplace's rules.
- **Local model (recommended)**: one click downloads llama.cpp b11239 and MiniCPM5 (2B Q4_K_M by default, 2B Q8_0 or 1B) with resumable, SHA-256-checked downloads; one click starts it on the GPU you pick (`FILAMENT_GPU` by default), and it becomes MiniAI's model. A crashed server turns the AI button red with Restart and its log; the server stops with the editor, and a server left behind by a crash is cleaned up.
- MiniAI chats with any OpenAI-compatible endpoint (local llama-server with MiniCPM5, Ollama, LM Studio, vLLM, OpenRouter, OpenAI), set up in **Model provider…**; the key is kept apart from the settings.
- The agent uses the editor's MCP tools through four approval modes (Plan, Ask, Accept edits, Auto) with Allow / Always allow in this chat / Deny cards; one assistant turn is one Edit ▸ Undo step; Stop cancels a turn.
- The AI button spins while MiniAI works, shows how many tool calls wait for approval, and turns red after a failed turn.
